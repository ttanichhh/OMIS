# OMIS

Лабораторные работы по дисциплине «Объектное моделирование интеллектуальных систем».

## Лабораторная работа 2

[Материалы работы](./lab2) содержат реализацию платформы мероприятий на Python, тесты, список ошибок исходной модели и отчёт.

- [Отчёт Соловей Т. В., группа 421703](./lab2/Отчёт_ЛР2_Соловей.docx)
- [Список ошибок](./lab2/Список%20ошибок.md)
- [Исходная объектная модель в Google Docs](https://docs.google.com/document/d/1M911idmSZVmOWeWubdYAETS1b0hojYr891wSlVZX758/edit?tab=t.0)

Для запуска нужен Python 3.10 или новее. Из корня репозитория выполни команды.

```bash
cd lab2
python3 main.py
```

Открой [приложение](http://127.0.0.1:8000/), зарегистрируй аккаунт и войди. Данные сохраняются в SQLite.

Проверки запускаются из папки `lab2`.

```bash
python3 -m unittest discover -s tests -v
```
