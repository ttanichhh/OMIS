# OMIS

Лабораторная работа № 2 «Реализация объектной модели». Демонстрационная платформа мероприятий на Python с экранами входа, каталога, создания и просмотра мероприятия.

## Запуск

В папке проекта выполни команду. Нужен Python 3.10 или новее.

```bash
python3 main.py
```

Открой [приложение в браузере](http://127.0.0.1:8000/). Для входа подойдёт любой логин. Данные хранятся до остановки приложения.
